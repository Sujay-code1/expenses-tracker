💰 Personal Expense Tracker – MERN Stack

A full-stack Personal Expense Tracker built using the MERN stack that helps users track income, manage expenses, set budgets, and analyze spending through summaries and charts.

This project demonstrates real-world full-stack development, secure authentication, REST APIs, and state management using Redux.

📌 Features

User Registration & Login

Secure Authentication using JWT

Add, Edit & Delete Income and Expenses

Expense Category Management

Monthly & Total Expense Summary

Category-wise Budget Allocation

Transaction History

Data visualization with charts

Fully responsive UI

🏗️ System Architecture
React Frontend  →  Express API  →  MongoDB Database


The frontend communicates with the backend using REST APIs.
The backend handles authentication, business logic, and database operations.
